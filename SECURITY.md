# Security Policy

## Reporting a vulnerability

If you find a security problem in EduCafe Hub, please report it privately instead of opening a public issue.

- Email: akashkumar9225.de@gmail.com
- Or open a private security advisory on GitHub for this repository.

Please include:

- What you found and where (tool or page, and the steps to reproduce it).
- What you think the impact could be.

We will confirm that we received your report, fix the problem, and then let you know when it is safe to share details publicly.

## What this project is

EduCafe Hub is a free, static website: every tool runs in the browser and no files are uploaded to a server. There is no user data stored on the site itself.

## Please do not

- Run automated scanners or load tests against the live site.
- Try to access other people's files, sessions or accounts.
- Share a vulnerability publicly before it is fixed.

## Scope

This policy covers the code and content in this repository and the live site at https://educafehub.pages.dev.
