💻 Filee — the free desktop app for heavy files

Filee is a free, open-source desktop app (Windows / Mac / Linux) that converts 260+ file formats — Word, Excel, video, audio, e-books, HEIC photos — fully offline, with no uploads. A desktop app cannot run inside a website, so use Filee alongside this hub:

  • Install Filee once on the cafe / school PC — search “Filee” on GitHub and download it from its official open-source repository.
  • Use the converter on this page for quick JPG / PNG / WebP jobs in the browser.
  • Use Filee at the counter for the big jobs a browser cannot do — DOCX → PDF, video files, HEIC photos from phones.

Both stay free and private: files are converted on your own computer and are never uploaded anywhere.

Paise kaise kamayein? Kaun paise dega?

Seedhi baat: koi website khud paise nahi deti. Paise aate hain — ads dikhane par advertisers se, ya dukaan par service charge se. Dono ke asal numbers neeche hain.

1) 💰 Google AdSense

Traffic badhne ke baad AdSense approval milta hai, phir ads se kamai hoti hai. India mein aam taur par 1,000 pageviews par lagbhag ₹40–₹200 mil sakta hai — topic aur season par nirbhar. Pehle 500–1,000 roz ke visitors lao, phir apply karo.

2) 🏪 Local ads — seedha paisa

Aas-paas ki coaching, mobile dukaan, coaching centre se banner/spot ke ₹500–₹2,000 per month le sakte ho. Ye AdSense se pehle aur zyada bharosemand kamai hai — bill/receipt ke saath deal pakki karo.

3) 🖨️ Dukaan par service charge

Asli kamai yahi hai: passport photo sheet ₹30–₹50, form ke liye photo resize/print ₹10–₹30, PDF print ₹5–₹10 per page. Tool free hai, lekin print, paper aur aapka time — uska charge customer deta hai.

4) 🔗 Affiliate + Donation

Photo paper, printer ink, pen drive jaisi cheezon ke affiliate links aur ek chhota sa support/donation button bhi jod sakte ho. Income chhoti hoti hai, par zero cost par extra hai.

⚠️ Jhoothe waadon se bacho

“Guaranteed income”, “ek click mein lakhon”, fake CPC ya khud apne ads par click karne wali tricks — in sab se bacho. AdSense aisi harkat par account hamesha ke liye band kar deta hai. Koi bhi kamai pakki nahi hoti; pehle visitors, phir paisa.

Phase 0 — Now (free, no login)

Today's income is the counter only: photo/PDF service charges and local banners (cards 2 and 3 above). The site stays free and no account is needed.

Phase 1 — With your own domain

Once the .com domain is in place, apply for Google AdSense — it asks for a Privacy Policy and Terms, which now exist in the Legal section at the bottom of this page. After approval, ads pay per view and click.

Phase 2 — After login launches

Only after login exists could any optional paid extra be considered — such as bulk/batch jobs or an ad-free option — and only if real users actually come. The basic tools stay free.

🔐 What login will unlock later

Saved tasks, a work history, favourite tools and your settings on every device. That needs the domain plus a small server, so it comes after the domain — see the Login Roadmap below.

Ye site ek hi file (index.html) mein hai, isliye naya tool jodna aasan hai — coding ka basic tareeka jaan lo to khud bhi jod sakte ho.

Feature jodne ke 5 step

  1. Upar nav mein ek naya link jodo: <a href="#mytool">My Tool</a>
  2. Ek naya <section id="mytool"> banao — kisi purane tool ka section copy karke badal do.
  3. Uske liye chhota sa JavaScript likho — file hamesha browser mein hi process karo, server par mat bhejo.
  4. Dono bhashaon ke liye I18N dictionary mein uski EN aur HI entry jodo.
  5. Test karo, phir file ko dobara deploy karo (neeche Free Live wale steps).

Free mein live kaise karein — step by step

Ye static site hai, isliye hosting bilkul free hai aur server ka kharcha zero. Apna domain (jaise educafehub.com) bhi free mein jod sakte ho.

Cloudflare Pages (recommended)

  1. dash.cloudflare.com par free account banao
  2. Workers & Pages → Create → Pages → Upload assets
  3. index.html (aur assets folder) upload karo — Deploy dabao
  4. Custom domain mein apna domain jodo; HTTPS apne-aap free mil jata hai

Netlify / GitHub Pages (alternatives)

  1. Netlify: app.netlify.com/drop par folder drag-drop karo — turant live link mil jata hai
  2. GitHub Pages: repo banao, index.html upload karo, Settings → Pages → Branch: main
  3. Teeno par SSL (HTTPS) free hai, bandwidth bhi aam traffic ke liye free hai
  4. Load: saara kaam visitor ke browser mein hota hai, isliye server load ~zero rehta hai — hazaron visitors par bhi site slow nahi hoti

Update kaise karoge?

Nayi index.html banao, wahi file dobara upload/deploy kar do — site 1 minute mein update ho jati hai. Purani file ki ek copy hamesha apne paas backup mein rakho.

    Ek saath kitne log? Kya ye crash hogi?

    Har school/cafe owner ke teen sawal — seedhe jawab, aur neeche ek live self-check jo page khulte hi is device par chalta hai.

    👥 Ek saath kitne log istemal kar sakte hain?

    Koi fix number nahi hai aur koi line (queue) nahi. Ye page kisi ek busy server par nahi chalta — har visitor ka apna phone/computer browser mein tool ka kaam karta hai, aur page khud ek bade global network (Cloudflare) se aata hai. Chahe 10 log kholein ya 10,000 ek saath, har kisi ka photo aur PDF ka kaam uske apne device par hota hai — isliye koi kisi ko slow nahi karta.

    💥 Kya ye crash ho jayegi?

    Visitors ki bheed se ye crash nahi ho sakti, kyunki kaam karne wali koi central machine hai hi nahi — kuch overload hota hi nahi. Imandaar limits: bahut purane phone par badi PDF mein thoda zyada samay lag sakta hai; page pehli baar load hote samay net chala jaye to do PDF tool (jo online load hone wali free library use karte hain) refresh karne ko kahenge; aur har website ki tarah, page tabhi khulega jab host network chalu ho. Aapki files kabhi problem nahi hain — ve device se bahar jaati hi nahi.

    ✅ Kya sab kuch thik chal raha hai?

    Saare 16 tool aur saare 31 daily link isi ek page par hain — alag-alag page hain hi nahi jo tootein. Page khulte hi ye khud ki jaanch karta hai: neeche wali status line asal mein load hue link ginti hai aur PDF library ke pahunchne ki pushti karti hai. Har line mein ✔ dikhe to is device par sab kuch istemal ke liye taiyaar hai.

    🔎 Self-check — page khulte hi is device par chalta hai

    Checking…

    Upar wali jaanch asal hai: ye ginti hai ki is browser ne abhi-abhi asal mein kya load kiya. Aam internet connection par chaaron mein ✔ dikhega. Kisi PDF library par ⚠ dikhe to page ek baar refresh kar dein.
